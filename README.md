# Flavium Sports Portal 2027

A responsive front-end sports portal for the NMIMS Shirpur campus, based on the SPTM / MPSTME programme structure and sports fixture idea provided.

## Run in VS Code
1. Extract `flavium-sports-portal.zip` to a folder.
2. Open that folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the **Live Server** VS Code extension and choose **Open with Live Server**.
4. No npm packages, server, or database are required for this demo.

## Features
- Dashboard with fixture statistics and upcoming matches.
- Fixture cards and table view.
- Search and filters for sport, school, gender and status.
- Match details modal.
- Sample league standings for cricket, box cricket and football.
- Sport cards and school quick filters.
- Responsive layout for desktop and mobile.
- SPTM and MPSTME team categories, including the supplied CSDS year restriction (Years 1–2 only).

## Important
The dates, scores, completed matches and live status are **sample data** for demonstration only. This is a front-end prototype; it does not connect to a backend or persist edits. Replace the demo fixture-generation logic in `script.js` with verified official data before publishing.
